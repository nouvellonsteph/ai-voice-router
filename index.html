Calculation assumptions and exclusions +

Selected routes. Hot shadow sends every minute to both configured route slots, even if they select the same target. Single-active sends English only to the English route and French only to the French route. It assumes local language detection, no paid classifier, and no duplicated handoff buffer.

Own cluster. “No Workers AI” uses an AI Gateway custom provider pointed at your HTTPS inference endpoint. Gateway core features are $0; your entered per-minute rate represents cluster or provider cost. Optional Gateway logging follows Workers Logs pricing and is not estimated.

Free allocation. Workers AI includes 10,000 neurons per active day. The estimate assumes even daily traffic; spikes can change the bill. All Workers and Durable Objects allowances are account-wide.

Durable Object. The installed client sends approximately 600 audio frames per minute; the estimate uses 600 as a conservative cadence. Cloudflare bills incoming WebSocket messages at 20:1, plus one connection request per session. Duration uses 128 MB for the full call because active provider WebSockets prevent hibernation.

Not modeled. Worker CPU, control frames, SQLite metadata, taxes, Enterprise discounts, retries, and other account traffic are excluded. Static asset requests and data transfer have no additional charge. Prices are USD public list prices, not a Cloudflare quote.
