# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/nouvellonsteph/ai-voice-router/security/advisories/new) and include reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

Do not include Cloudflare credentials, account identifiers, access tokens, or captured user audio in a report.
